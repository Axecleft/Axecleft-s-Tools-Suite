# Variants and builds (Adventurers and Minions)

**Where:** [Adventurers and Minions](Adventurers-and-Minions): the class lists and **Classes and levels** step for variant classes, class feature variants and gestalt; the **Spells** step for domain wizards; the start page for **Build profiles** and **Prestige requirements** (GM).

Unearthed Arcana's variant rules (in the SRD), and the GM's control over how A&M builds each class and which prestige classes a character qualifies for.

<a id="variant-classes"></a>
## Variant classes

The variant classes of Unearthed Arcana are in their own group of the class lists:

| Standard class | Variants |
|---|---|
| Barbarian | Totem barbarians: ape, bear, boar, dragon, eagle, horse, lion, serpent, wolf |
| Bard | Bardic sage, divine bard, savage bard |
| Cleric | Cloistered cleric |
| Druid | Druidic avenger |
| Fighter | Thug |
| Monk | The eight monk fighting styles |
| Paladin | Paladins of freedom, slaughter and tyranny |
| Ranger | Planar ranger, urban ranger |
| Rogue | Wilderness rogue |
| Sorcerer | Battle sorcerer |

- A&M makes each from its standard class with the variant's changes: hit die, base attack, saves, class skills and skill points, alignments, spell tables (a battle sorcerer's one fewer spell a day and known), spell list (a paladin of tyranny's, the bardic sage's additions), and bonus feats (a bear totem's Toughness, Improved Grapple and Great Fortitude; a monk style's three fixed feats; no 1st-level bonus feat for a thug).
- On the actor it's a class item named after it, for example "Barbarian (Bear Totem)", with the standard class's features less those it loses. What it gains shows as notes on the sheet, and as D35E changes where they're plain bonuses (+2 on a monk style's skill).
- Edit reads them back.
- Random never picks a variant by itself: choose one under **Class**.

With **Spontaneous casting** off, **Cleric**, **Druid**, **Paladin**, **Ranger** and **Wizard (Spontaneous)** are variant classes too (see [Spontaneous casting](#spontaneous-casting)).

The world setting **Variant classes** (on by default) turns off the variant classes, the class feature variants and domain wizards.

<a id="class-feature-variants"></a>
## Class feature variants

**Classes and levels** offers Unearthed Arcana's swaps for a class feature, for each class that has them. Point at one to read what it gives.

| Variant | Class | Notes |
|---|---|---|
| Whirling frenzy | Barbarian | Changes rage: no greater or mighty rage or indomitable will; evasion while in a frenzy at 14th. |
| Favored environment | Ranger | Instead of favored enemy. |
| Turning undead by level check | Cleric, paladin | |
| Planar banishment | Cleric | |
| Aspect of nature | Druid | Instead of wild shape. |

- Totem barbarians and the other variant classes can take them too.
- What they give shows with the class features and goes on the actor as notes on the class. The features they replace leave the actor (D35E's own disabled abilities).
- Edit reads them back and changes them.

### Specialist wizard variants

Once a wizard's specialist school is chosen (on **Spells**), Classes and levels offers its school's three variants. Each gives up the familiar, the wizard bonus feats or the specialty spell slot.

| School | Variants |
|---|---|
| Abjuration | Resistance to energy, aura of protection, spontaneous dispelling |
| Conjuration | Rapid summoning, enhanced summoning (Augment Summoning instead of Scribe Scroll), spontaneous summoning |
| Divination | Enhanced awareness, the bonus feat list, prescience |
| Enchantment | Cohort, social proficiency, extended enchantment |
| Evocation | Energy affinity, energy substitution, overcome resistance |
| Illusion | Chains of disbelief, shadow shaper, illusion mastery |
| Necromancy | Skeletal minion, undead apotheosis, enhanced undead |
| Transmutation | Enhance attribute, spell versatility, transmutable memory |

On the actor:
- the familiar, Scribe Scroll or bonus feats leave (D35E's disabled abilities);
- a variant that replaces the specialty spell takes away the school slot;
- the class skills it gives are added (an enchanter's Bluff, Diplomacy, Gather Information, Intimidate and Sense Motive);
- Augment Summoning is added as a feat;
- the rest are notes on the class.

A diviner's bonus feat list drops the metamagic feats for Alertness, Blind-Fight, Improved Initiative, Lightning Reflexes and Skill Focus. A variant of another school than the one chosen is ignored.

<a id="domain-wizard"></a>
## Domain wizard

A wizard's **Specialist school** list on **Spells** also offers the 13 arcane domains: abjuration, antimagic, battle, cold, conjuration, divination, enchantment, evocation, fire, illusion, necromancy, storm, transmutation.

- A domain wizard gives up no schools.
- Its domain spells go in its spellbook as soon as it can cast them, not counted against the spells it learns. Chill metal, control winds and the other non-wizard spells count as wizard spells.
- It prepares one domain spell of each level in its domain slot.
- Its domain spells are cast at +1 caster level.
- On the actor, the domain is a D35E domain feat listing its spells, so the sheet lets them in the slot.
- A spontaneous domain wizard casts one more spell a day of each level, for its domain spells.
- Edit reads it back.

<a id="spontaneous-casting"></a>
## Spontaneous casting

The world setting **Spontaneous casting** (off by default) makes every caster cast spontaneously:

| Class | Spontaneous |
|---|---|
| Cleric, druid | Spells known by Unearthed Arcana's spontaneous divine casters table, with their domain spells (no domain slot) or *summon nature's ally* of each level, and one more spell a day of each level. |
| Paladin, ranger | Two more spells known of each level than they cast a day. |
| Wizard | Casts any spell in its spellbook (Curios' spellbook too) with its spells a day; nothing prepared. |
| Specialist wizard | No school slot: one more spell a day of each spell level, for its school's spells only. |

- Their variants follow (a cloistered cleric too). A spontaneous wizard counts for the Dragon Disciple's "casts arcane spells without preparation".
- Edit turns an actor's casters spontaneous when the setting is on.
- A caster inside a gestalt pairing is spontaneous too.

With the setting off, choose **Cleric**, **Druid**, **Paladin**, **Ranger** or **Wizard (Spontaneous)** from the variant classes for one spontaneous caster.

<a id="gestalt"></a>
## Gestalt

Tick **Gestalt** on **Classes and levels** (or on the [Random](AM-Random) page) and each level takes two classes (Unearthed Arcana).

- On the actor each pairing is one class A&M builds from the two, named for example "Fighter // Wizard": the better hit die, base attack bonus, saves and skill points, both class skill lists, and both classes' features, each at its own class level. No custom classes are needed in your compendiums. Its description notes the two classes it was built from.
- **Spellcasting** stays with the casting class: a copy of it at level 0 carries its spell table, and the gestalt class gives a **Bonus Arcane/Divine Spellcaster Level** at every level, spent on that class's spellbook. A Cleric // Wizard 5 casts as a 5th-level cleric and a 5th-level wizard.
- **Psionic classes** go on at level 0 the same way, with a locked class feature, **Gestalt Psionics**, that adds the power points of their gestalt levels and their manifester levels. A second psionic class learns other powers than the first.
- Bonus feats, prerequisites (class levels) and alignment follow each class by its own level. Gestalt characters have no multiclass XP penalty.
- **Standard gear:** arms and armor from the class with the better base attack bonus, plus the other class's worn magic items for the slots left empty. Starting gold for a 1st-level PC is the better of the two classes'.
- Random characters, Choose for me, Edit and Review all handle gestalt levels.

<a id="builds"></a>
## Builds

Random characters, and A&M's own choices (**Choose for me**, **Fill in**, **Standard gear**, **Roll again**), follow a build for each class: its ability order and increases, skills, feats, alignments, spells and gear. Several classes have more than one:

| Class | Builds |
|---|---|
| Fighter | Sword and board, archer, two-handed, two-weapon, tripper |
| Rogue | Swashbuckler, archer, two-weapon, face |
| Ranger | Archer, two-weapon |
| Cleric | Battle cleric, healer |
| Wizard | Evoker, controller, summoner |
| Sorcerer | Blaster, charmer |
| Druid | Caster, shapeshifter |
| Paladin | Mounted, two-handed |
| Barbarian | Greataxe, spear charger |
| Monk | Kama, unarmed |

The build changes the gear too: an archer's bow gets the better enhancement, a two-handed fighter has a greatsword and no shield, a two-weapon fighter two shortswords.

- **Random** picks a build for each class, or the one chosen under **Build**.
- **Classes and levels** shows each class's build when it has several, and lets you choose it. Review shows it after the class.

<a id="build-profiles"></a>
## Build profiles

**Where:** the start page → **Build profiles**. GM only.

> 📷 **Screenshot:** the Build profiles page with the fighter's archer build open.

| Control | What it does |
|---|---|
| Class | The class whose builds you're changing. |
| Build | The class's own build, one of A&M's (an archer, a healer…), or **New build**. |
| The build's fields | The ability order and increases, skills, feats, alignments, favourite spells, weapons, and a cleric's domains or a wizard's schools. One per line. What's left empty follows the class's own build. |
| **Save** | Keeps the build in the world. |
| **Hide** | Takes one of A&M's builds off the lists. |
| **Forget yours** | Goes back to A&M's build. |
| **Export** / **Import** | Move your builds to another world. |

You can also rename and change a class's own build.

<a id="prestige-requirements"></a>
## Prestige requirements

**Where:** the start page → **Prestige requirements**. GM only.

The requirements A&M checks before each prestige class's first level (see [Prestige classes](AM-Build#prestige-classes)). The SRD's come with A&M: 15 core and 9 psionic prestige classes.

> 📷 **Screenshot:** the Prestige requirements page with a prestige class open.

| Control | What it does |
|---|---|
| Prestige class | Every prestige class found, with where its requirements come from: the SRD's, yours, or none. |
| Requirements | Race, alignment, base attack bonus, skill ranks, feats, spellcasting, psionics, sneak attack, martial weapons, languages, and a special requirement shown as a reminder. |
| **Save** | Keeps yours for this world. They replace the SRD's. |
| **Use the SRD's** | Goes back to the SRD's requirements. |
| **No requirements** | The class has none. |
| **Export** / **Import** | Move your requirements to another world. |

Give a custom or homebrew prestige class its own requirements the same way.
