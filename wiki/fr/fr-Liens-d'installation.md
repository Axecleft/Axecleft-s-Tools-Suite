# Liens d'installation

**Où :** dans Foundry, écran de configuration → **Modules complémentaires** → **Installer un module** → collez le lien dans **URL du manifeste** → **Installer**.

Ouvrez un module ci-dessous et copiez le lien de votre version de Foundry avec le bouton de copie du bloc. Ces liens pointent toujours vers la dernière version.

- **Foundry 13 et 14** (D35E 3.x) : versions 1.14.x.
- **Foundry 11** (D35E 2.4.3) : versions 1.11.x.

Vous préférez une liste déroulante ? Utilisez le [sélecteur de liens d'installation](https://axecleft.github.io/Axecleft-s-Tools-Suite/?lang=fr).

## Mettre à jour

Foundry installe les mises à jour avec **Tout mettre à jour** dans **Modules complémentaires**. Avec la [Suite d'outils d'Axecleft](fr-Suite-d'outils-Axecleft), le MJ est prévenu quand une mise à jour sort.
