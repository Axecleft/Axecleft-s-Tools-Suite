# Install links

**Where:** in Foundry's Setup screen → **Add-on Modules** → **Install Module** → paste the link into **Manifest URL** → **Install**.

Open a module below and copy the link for your Foundry version with the code block's copy button. These links always point to the latest release.

- **Foundry 13 and 14** (D35E 3.x): versions 1.14.x.
- **Foundry 11** (D35E 2.4.3): versions 1.11.x.

Prefer a drop-down? Use the [install link picker](https://axecleft.github.io/Axecleft-s-Tools-Suite/).

## Updating

Foundry installs updates with **Update All** on **Add-on Modules**. With [Axecleft's Tool Suite](Axecleft's-Tools-Suite) installed, the GM is told when an update is out.
